# BTG Pod de Talentos

Protótipo navegável de um produto para recrutadoras em feiras de carreira. O candidato encosta o celular num pod NFC, entra com o LinkedIn, escolhe o ano e anexa o currículo. A recrutadora avalia no WhatsApp com um toque (Forte, Médio ou Fraco) e revisa os melhores candidatos num painel.

## Arquivos

* `public/prototipo.html`: protótipo completo (fonte da verdade). Abra no navegador. Imagens embutidas.
* `public/btg-pod-talentos-video.mp4`: vídeo demo (45 s, 16:9).
* `assets/`: imagens soltas (logo, pod, estande, foto do candidato, tela bloqueada).
* `docs/prompt-lovable-btg-pod-de-talentos.md`: especificação detalhada (cores, textos, tempos das animações, roteiro do WhatsApp).
