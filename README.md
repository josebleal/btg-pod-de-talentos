# Remembr

Remembr ajuda recrutadoras a lembrar de cada candidato que conhecem em feiras de carreira e eventos.

1. **Candidato:** encosta o celular num pod NFC no estande, entra com o LinkedIn, escolhe o ano e anexa o currículo, em cerca de 15 segundos.
2. **Recrutadora:** recebe o candidato no WhatsApp e avalia com um toque (Forte, Médio ou Fraco). Se quiser, deixa uma observação, na hora ou depois.
3. **Depois do evento:** revisa os melhores candidatos num painel com foto, observações, currículo e LinkedIn.

Cada empresa cliente recebe uma página própria, tematizada com as cores dela. Este repositório traz o exemplo da parceria com a **BTG Pactual**.
